# UI polish: motion, Kai font, Cards feedback

Status: proposed 2026-11-22 (lead). No stored-format or sync change. Research behind it: Hugo's project doc
`claude/ui-repo-research-report.md` (repo review, 2026-11-22); not in this repo.

## 1. What Hugo asked (2026-11-22)
Improve graphics, fluidity, look and ease of use, borrowing from open-source repos where they fit. Hugo's answers to the
review's questions:
1. No-UI-library rule: allow two tiny headless helpers, `ios-haptics` and `@formkit/auto-animate`. No Motion.
2. Near misses in Cards: a typo (`near`) gets one retry; wrong tones (`tones`) stay wrong, with the wrong syllables shown.
3. Swipes on Cards: swipe left = Next, only once the answer is shown. Never to grade.
4. Kai font: LXGW WenKai Medium, self-hosted, only where `--kai` is used today (Cards hanzi, 米字格, Sheets Cards mode).
5. Reduced motion: short fades instead of no animation.
6. Word panel at half height: parked until Hugo has used batch A for a few days (§5).

## 2. Decisions
- **D1 iPhone first.** View Transitions and the haptic trick ship behind a device-only flag (`localStorage hz.motion`,
  never synced, like QUICK-1) for Hugo to try on the Home Screen app (Pages deploys only from `main`). React issue
  #35336 reports enter/exit transitions crashing iOS Safari 26.1. If the probe crashes or stutters, WP1 uses CSS only
  (`@starting-style` + a closing state), no `<ViewTransition>`.
- **D2 Routes.** One `<ViewTransition>` around the view in `App.tsx`; `setRoute` inside `startTransition` with a
  transition type: `forward` (deeper: Settings → More → Stats, Grammar list → point) slides in from the right with
  `--ease`; `back` slides the other way; tab switches and Previous/Next cross-fade. The tab bar has its own
  `view-transition-name`, so it stays still. Inner lists (Sheets search with `useDeferredValue`) get `default="none"`:
  no fade per keystroke.
- **D3 Everything that opens also closes with motion.** `Sheet` and `.pop` menus play a short exit (sheet down, menu
  scale-out, scrim fade) before `onClose`, whether closed by the button, backdrop, Esc or drag. Exit at most 0.25 s,
  with a timeout fallback so a missed `animationend` never leaves a dead sheet. A parent that unmounts a sheet without
  calling `onClose` still removes it at once (acceptable).
- **D4 Springs.** New token `--spring-ios`: a CSS `linear()` curve (critically damped spring, about 0.45 s, 30–40
  points, generated once by a throw-away script). Replaces `--spring` on the switch knob, chips and tab icons.
  `--ease` stays for sheets.
- **D5 Reduced motion = fades.** The global `animation: none` rule (`styles.css:647`) becomes: slides and scales turn
  into opacity fades of 0.15 s or less; View Transition pseudo-elements fade too. Feedback (flash, highlight) stays,
  the shake goes.
- **D6 Long list.** Sheets rows get `content-visibility: auto` with an intrinsic size per layout (one-line desktop row,
  two-line phone row); `PAGE` goes from 150 to 400. Every row stays in the DOM: answer fields, the Return walk and the
  e2e hooks keep working. No virtualisation.
- **D7 Kai font.** LXGW WenKai Medium (OFL-1.1) from a pinned GitHub release, checked by sha256, split at build time
  into `unicode-range` woff2 chunks with `cn-font-split`, so the phone downloads only the characters it shows. Output in
  `public/kai/` (gitignored, built like `public/dict/`), cached at runtime (`CacheFirst`, cache `fonts`), never precached.
  `font-display: swap`; `--hanzi` (list text) stays PingFang. The OFL licence ships next to the fonts. Never subset
  from Hugo's words (public repo).
- **D8 Cards feedback.** Wrong: the answer field shakes (3 × ±10 px, 0.3 s) and, for `tones`, the syllables in
  `wrongAt` turn `--wrong`. Right: a short `--green-tint` flash. `near`: "Almost, check the spelling", field kept, one
  retry; a second miss is wrong (and sets the Wrong tag as today). Haptic tick on real taps of Check, Next, GradeBar
  and status chips (`ios-haptics`; no buzz on Return or programmatic submits, by design). Card change: the card slides
  out left, the next slides in, keyed by note id.
- **D9 Small lists move.** `@formkit/auto-animate` on lists of 100 rows or fewer: Grammar results, Grammar filter
  chips, Cards missed words. Never on the Sheets list. It respects reduced motion on its own.

## 3. Work packages (disjoint files within a batch)

### Batch A — motion at 0 KB (three ui-dev in parallel, after WP0 passes)
**WP1 — routes (ui-dev).** Files: `src/ui/App.tsx`, new `src/ui/motion.css` (imported by `App.tsx`).
D2; remove the WP0 flag (on for everyone); `::view-transition-*` rules and their reduced-motion fades (D5) live in
`motion.css`. Cards and Review (full-screen) enter with a fade.

**WP2 — sheet and menu exits (ui-dev).** Files: `src/ui/panel.tsx`, `src/ui/panel.css`.
D3. In `useSheetDrag`: scrim opacity follows `dy`; dragging up gets rubber-band resistance (`dy × 0.2`). New
keyframes and the `.closing` classes go in `panel.css`; do not edit `styles.css` (WP3 owns it). Keep the touch-listener
approach (iOS `pointercancel` gotcha) and every test hook.

**WP3 — tokens, reduced motion, long list (ui-dev).** Files: `src/styles.css`, `src/ui/sheets/sheets.css`,
`src/ui/Sheets.tsx` (only `PAGE` and the step).
D4, D5 (except `::view-transition-*`), D6. Also put `'LXGW WenKai'` first in `--kai` (WP5 supplies the font; until it
ships the stack falls through as today).

Checks: lead runs `npx tsc --noEmit -p .`, `npm test`, `npm run build`, `e2e/layout.py`; then qa (sonnet) on batch A.

### Batch B — Kai font (parallel with batch A)
**WP4 — font build (engineer).** Files: new `scripts/build-kai.mjs`, `package.json` (`dev`/`build` script lines),
`.gitignore`.
D7. Follow `scripts/build-cfdict.mjs`: reuse a valid existing output, fail in CI when missing, warn and skip on a
laptop. Pinned release URL + sha256 in the script. The cloud shell may not reach release downloads: test with a local
TTF via `KAI_FILE`, and the real download through a `data.yml`-style run on a branch.

**WP5 — font delivery (release).** Files: `vite.config.ts`, `.github/workflows/deploy.yml`, `index.html`,
`package.json` devDependency `cn-font-split` (coordinate the one `package.json` edit with WP4: release adds the
dependency, engineer the script lines).
`runtimeCaching` `CacheFirst` for `/kai/` (cache `fonts`), `globIgnores` + `navigateFallbackDenylist` for `kai/**`,
deploy cache step keyed on `build-kai.mjs` like cfdict, `<link rel="stylesheet">` to the generated CSS. CSP already
allows `font-src 'self'`.

Checks: qa (sonnet) on batch B: build output size, the font is not in the precache manifest, Cards hanzi render in
WenKai in Chromium (`e2e/cards.py` screenshot, not committed).
